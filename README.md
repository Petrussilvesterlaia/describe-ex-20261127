## The word

**Unsubscribed.**

One word, and the whole breakup is in it: the endless messages, the
drama delivered daily like a newsletter nobody asked for — until you
finally hit unsubscribe. No insult, no shouting. Just the quiet click
of opting out for good.

## How it works

`main.py` validates the word (exactly one word, 1–111 characters, no
whitespace inside or around it) and writes it to `/output/entry.txt`
with no trailing newline, then reads the file back and verifies it
byte for byte.

```sh
python3 main.py
```
